## Decisions and findings worth keeping
- **Migration runner now wraps each file in a transaction.** 008 rebuilds a table (create, copy, drop, rename); a crash between drop and rename would otherwise lose the notes table. Verified on a copy of the real database (two notes backfilled, integrity ok, second start a no-op; 8 cellar wines classify as Check window).
- **The Swift app does not port `identityKey`.** The refresh prompt follows the PATCH response's `enrichment_stale` and only appears for an edit that touched an identity field; web decides before saving with the shared function.
- **A price result must not overwrite review-derived fields.** The two lookups run concurrently and answer in either order; `Wine.applying(_:from:)` takes only what each kind owns (a test pins the late-stale-price case).
- **Fixtures.** `duplicate-match.json` had predated the bottling-aware check (#38); regenerated, and the exporter now passes the bottling.
- **Colour bug (WI-8) not reproduced.** Nothing in the selection → patch → display path drifts, and a test pins it; reproducing the developer's "white" needs a real scan (a metered call), so it is left for the device pass.
- **Web `npm run build` emits `.js` files beside the sources** (the web `tsc` has no `noEmit`). Use `npx vite build`, or add `noEmit` — not changed here.
