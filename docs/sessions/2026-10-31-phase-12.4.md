## The live query (2019 La Crau) — what else it showed

Saved, trimmed to the fields the price module reads, as `backend/tests/fixtures/serper-shopping-la-crau-2019.json` and replayed offline through the real `querySerper`.

- **Pass 2 drops listings that have no Serper `link`, and most don't.** The fallback filter requires `item.link` (since #16, 2026-08-05), but `buildFallbackResult` never uses it: it builds a Google search URL from the merchant name. **29 of 40** items had no `link`, including every exact-2019 listing except Benchmark's (CaskCartel $249.99, Tribeca 6×750, BlockCellar). So the stored five were Benchmark plus four **vintage-unknown** listings, and one of those, JAX, is the **La Crau Blanc**. Without the filter the same response keeps five 2019 listings. Red fixture. A defect not in the spec; it belongs with WI-2/WI-3 because it decides which retailers appear at all.
- **Colour is not a matching dimension.** SommPicks' and CaskCartel's *La Crau Blanc 2019* match the red La Crau as the exact wine. The same gap as the Vieux Télégraphe blanc above, from the other side. Not in the spec; worth a decision (it's a bottling difference in all but name).
- **"750 mL | 6 bottles" is not read as a six-pack** (BlockCellar, $445.71), so it would count as a single bottle. Red fixture (WI-5 territory).
- **A Shopping query costs 2 credits, not 1.** Serper's response reported `credits: 2`. `HARD_REFRESH_CREDITS.price` and the Phase 9.2 per-wine arithmetic assume 1. Recorded in `CLAUDE.md` §15; the constant is unchanged pending a second observation.

## Other things the replay turned up

- **Modifier noise is widespread.** 17 wines currently raise the bottling prompt, several on junk options: "Blogs" (Conterno, from a URL path), "Blend" (Mangot, Grand Village), "Piper" and "Holiday Sparkles" (Charles Heidsieck; Piper is another house), and URL path words as above. This noise, more than re-evaluation, is why the banner feels like it keeps asking. URL path segments are an obvious first filter; WI-4's answered-state fix alone won't stop a first ask on junk.
- **Sansonnet's replay verdict is REJECTED** (denomination unknown from the URL alone) although the live run stored the page today. The live run had the Serper title; the replay has only the URL, so this is a replay limitation, not a live-path bug.
- **La Crau 2019 has `review_data = []`** while the probe memory says `found` at five shops. Out of WI-0's scope; worth an `explain-wine` look in 12.4.
